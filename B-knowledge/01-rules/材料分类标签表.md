# 银龄安心材料分类标签表

## 一、用途

本表用于统一上传后的材料初步分类、用户确认和工作流路由。分类结果只表示“材料是什么”，不直接代表药品真假、产品疗效、诈骗结论或违法判断。

分类必须综合图片、OCR文字、批准或备案信息、材料版式和上下文，不得只根据单个关键词、包装颜色或品牌名称判断。

## 二、一级分类标签

| 标签代码 | 标签名称 | 主要判断依据 | 排除或冲突条件 | 信息不足时的处理 | 工作流去向 |
|---|---|---|---|---|---|
| `MEDICINE_PACKAGE` | 正规药品包装 | 出现药品通用名称、剂型、规格、批准文号、上市许可持有人或生产企业；批准文号格式与药品相符 | 只有宣传功效而无药品身份信息；明确标注保健食品、普通食品或医疗器械 | 要求补拍药盒正反面、批准文号和企业区域 | 药品身份核验与药品解读 |
| `DRUG_INSTRUCTION` | 药品说明书 | 出现“请仔细阅读说明书并在医师指导下使用”，并包含成分、适应症或功能主治、用法用量、禁忌、注意事项等章节 | 只有广告、科普文章、购买页面或药店介绍 | 要求按顺序补充全部页面，标记可能缺页 | 说明书OCR、章节提取与解释 |
| `PRESCRIPTION` | 医院处方 | 包含医疗机构、患者信息、处方日期、药品名称、规格、用法用量、医师签名或处方编号 | 药店订单、购药小票、个人手写用药记录 | 隐藏个人敏感信息后重新拍摄关键区域 | 处方字段提取与药品核对 |
| `MEDICATION_LIST` | 门诊或出院用药清单 | 医疗机构出具，列出多个药品及用法、频次、疗程等信息 | 单张药盒、多药合照但没有医疗机构清单结构 | 要求补充标题、机构、日期及完整药品列表 | 多药整理与问医生清单 |
| `MULTI_DRUG_IMAGE` | 多药材料 | 同一组图片中出现两种及以上药盒、药瓶、说明书或明确药品名称 | 同一药品的正反面照片或同一说明书的多页图片 | 先对图片分组，再让用户确认药品数量 | 多药识别与整理 |
| `HEALTH_FOOD` | 保健食品 | 出现保健食品标志、注册或备案信息、保健功能及“不以治疗疾病为目的”等相关标识 | 存在国药准字等药品批准信息；仅凭“增强免疫力”等宣传词不能确定 | 要求补拍标志、注册备案号和产品类别区域 | 产品身份与宣传风险分析 |
| `ORDINARY_FOOD` | 普通食品 | 出现食品名称、配料表、营养成分表、食品生产许可证编号和食品执行标准 | 出现药品批准文号、保健食品注册备案或器械注册信息 | 要求补拍包装背面及配料、许可证区域 | 食品身份说明与宣传风险分析 |
| `MEDICAL_DEVICE` | 医疗器械 | 出现医疗器械注册证编号或备案编号、产品技术要求编号、结构组成和预期用途 | 药品、保健食品或普通食品信息明确 | 要求补拍注册备案编号及预期用途 | 器械身份说明与宣传风险分析 |
| `HEALTH_PROMOTION` | 健康宣传材料 | 海报、传单、文章、直播页面或宣传图，包含疾病、疗效、专家、案例、功效承诺或产品推荐 | 仅为药品说明书原文；没有推广或劝购语境的正规科普材料 | 保留完整标题、发布主体、宣传原文和联系方式 | 防骗宣传风险分析 |
| `SALES_CHAT` | 推销聊天 | 微信、短信、群聊、私信或电话转写中出现产品推荐、价格、疗效承诺、付款催促、私人联系方式 | 普通家人聊天、医生正常沟通且无销售行为 | 要求补充前后文、对方身份及付款相关内容 | 身份、宣传、交易和情绪风险分析 |
| `LECTURE_INVITATION` | 健康讲座或活动邀请 | 出现免费体检、健康讲座、专家义诊、领取礼品、会销地址和报名联系方式 | 医疗机构正常预约通知，且没有产品销售或诱导信息 | 要求补充主办方、地址、收费和产品信息 | 身份与活动风险分析 |
| `ORDER_RECEIPT` | 订单或收据 | 出现商品名称、数量、金额、商户、订单号、购买时间、退款或售后信息 | 银行或支付平台转账凭证；只有二维码而无订单信息 | 要求补充订单详情和商户信息 | 交易核验与证据整理 |
| `PAYMENT_PROOF` | 付款或转账凭证 | 出现付款金额、收款方、账户、交易时间、交易单号或支付状态 | 只有商品订单但没有实际付款信息 | 提示遮挡完整卡号、身份证号等敏感信息 | 交易风险、家属简报与证据整理 |
| `AGREEMENT_REFUND` | 会员协议或退款规则 | 出现会员费、服务协议、自动续费、保证金、退款条件、违约责任等 | 普通产品说明、单纯订单页面 | 要求上传完整条款和签署、付款页面 | 交易条款与退款风险分析 |
| `QR_CODE_ONLY` | 仅二维码或链接 | 材料主要是二维码、短链接或陌生链接，缺少主体、产品和用途说明 | 同一材料中已清楚出现合法主体和完整业务信息 | 不自动打开链接；要求用户补充二维码来源和上下文 | 链接风险提示与人工确认 |
| `OTHER_DOCUMENT` | 其他相关材料 | 与用药、健康消费或证据整理相关，但不符合上述类型 | 与项目完全无关的图片或文档 | 说明已识别内容并请用户选择最接近的类别 | 人工确认后路由 |
| `UNDETERMINED` | 无法判断 | 图片模糊、遮挡严重、文字过少、内容冲突或无法识别材料类型 | 已存在足以支持某一类别的明确证据 | 不强制分类；要求重新拍摄或由用户手动选择 | 停止自动路由，进入分类确认 |

## 三、二级辅助标签

二级标签用于工作流分析，可以多选，但不能替代一级材料类别。

### 1. 药品信息标签

```text
HAS_APPROVAL_NUMBER      出现批准文号
HAS_DRUG_NAME            出现药品通用名称或商品名称
HAS_DOSAGE_FORM          出现剂型
HAS_SPECIFICATION        出现规格
HAS_DOSAGE_TEXT          出现用法用量文字
HAS_CONTRAINDICATION     出现禁忌章节
HAS_WARNING              出现注意事项或警示语
POSSIBLE_MISSING_PAGE    说明书可能缺页
MULTIPLE_PRODUCTS        材料中疑似存在多个产品
IDENTITY_CONFLICT        药盒、说明书或数据库信息冲突
```

### 2. 消费风险标签

```text
IDENTITY_CLAIM           医生、专家、医保或官方身份声称
CURE_CLAIM               治愈、根治或包治百病声称
NO_SIDE_EFFECT_CLAIM     绝对无副作用声称
REPLACE_MEDICINE         暗示替代药品或正规治疗
STOP_MEDICINE_REQUEST    要求或诱导停药
PRIVATE_TRANSFER         要求向个人账户转账
VERIFICATION_CODE        索要验证码
URGENT_PAYMENT           催促立即付款
SECRECY_REQUEST          要求不告诉家属
FEAR_PRESSURE            使用疾病恶化或错过治疗恐吓
REFUND_UNCLEAR           退款条件缺失或不清楚
```

二级风险标签只能表示“发现需要分析的信号”，最终风险结论必须结合上下文并引用原文证据。

## 四、分类优先级

当一组材料同时包含多种类型时，按材料独立分类，不强制合并为一个标签。例如：

```text
药盒照片 → 正规药品包装
说明书照片 → 药品说明书
微信截图 → 推销聊天
付款截图 → 付款或转账凭证
```

如果系统必须为整组材料选择主路由，使用以下顺序：

1. 付款、验证码、私人转账、诱导停药等红色风险材料；
2. 推销聊天、健康宣传和活动邀请；
3. 药品说明书、处方和药品包装；
4. 保健食品、普通食品和医疗器械；
5. 其他材料或无法判断。

主路由不应删除其他材料的分类结果。

## 五、置信度与用户确认

| 置信度 | 系统行为 |
|---|---|
| `0.85–1.00` | 显示推荐分类，允许用户修改后继续 |
| `0.60–0.84` | 必须显示判断依据并要求用户确认 |
| `<0.60` | 返回“无法判断”，不得自动进入药品剂量或高风险结论流程 |

无论置信度多高，以下情况都必须让用户确认：

- 药名、批准文号、剂型或规格存在冲突；
- 药品与保健食品类别冲突；
- OCR识别到剂量或频次，但图片模糊；
- 同一组材料疑似包含多个产品；
- 只有二维码、局部聊天或缺少上下文；
- 分类结果将进入用法用量解释。

```json
{
  "material_id": "string",
  "primary_label": "DRUG_INSTRUCTION",
  "primary_label_name": "药品说明书",
  "secondary_labels": ["HAS_APPROVAL_NUMBER", "HAS_DOSAGE_TEXT"],
  "confidence": 0.91,
  "evidence": [
    {
      "source": "image_2",
      "text": "用法用量",
      "reason": "出现标准说明书章节标题"
    }
  ],
  "missing_information": [],
  "needs_user_confirmation": true,
  "recommended_route": "medicine_instruction_workflow"
}
```

## 七、分类安全规则

1. `正规药品包装`只表示材料具有药品包装特征，最终身份仍需按批准文号核验。
2. 不得根据“祖传、天然、进口、特效”等词语判断产品类别。
3. 不得把食品或保健食品的功能声称转换为治疗适应症。
4. 不得因为出现“医生、专家、官方”等词语直接认定冒充或诈骗。
5. 不得自动打开二维码、短链接或陌生网页。
6. 无法判断时必须停止推断，返回缺失信息和重新拍摄要求。
7. 所有分类结果都允许用户纠正，纠正记录应进入测试样本和后续优化。
