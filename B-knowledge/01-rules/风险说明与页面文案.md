# 风险说明与页面文案

> 交付方：成员B（知识库、内容规则与数据资料）  
> 交付对象：成员A（产品、UI与网页前端）  
> 适用页面：分类确认页、药品结果页、防骗结果页、家属简报页及相关状态页。

## 一、使用原则

- 风险提示必须同时使用图标、标题和文字，不能只用颜色。
- 标题使用短句，先告诉老人现在该做什么。
- 每张风险卡默认最多显示三条证据或三条行动。
- 绿色不表示“绝对安全”，红色也不直接写“确定诈骗”或“确定违法”。
- 红色结论必须有材料中的直接证据。
- 信息不足时显示“暂时无法判断”，不得强行给出风险等级。
- 不使用责备、羞辱、恐吓或过度专业的表达。

## 二、三级风险文案

接口值与页面含义统一如下；页面可以在详情中使用更口语化的行动标题，但不得改变风险含义：

| 接口值 | 页面含义 |
|---|---|
| `green` | 暂未发现明显风险 |
| `yellow` | 有些信息需要进一步核实 |
| `red` | 建议立即停止相关操作 |

### 1. 绿色：暂未发现明显风险

| 项目 | 页面文案 |
|---|---|
| 卡片标题 | **暂未发现明显风险** |
| 简短说明 | 根据目前材料，没有看到明显的高风险情况。 |
| 补充提醒 | 材料可能不完整，重要信息仍请通过正规渠道核实。 |
| 主按钮 | **查看分析结果** |
| 次按钮 | **请家里人一起看** |

不得使用：

- “完全安全”；
- “可以放心购买”；
- “一定没问题”；
- “已经确认是真药”。

### 2. 黄色：有些信息需要进一步核实

| 项目 | 页面文案 |
|---|---|
| 卡片标题 | **有些信息需要进一步核实** |
| 简短说明 | 目前有些身份、宣传或付款信息没有确认清楚。 |
| 行动提示 | 请先核实清楚，再决定是否继续。 |
| 主按钮 | **查看要核实的内容** |
| 次按钮 | **请家里人一起看** |

常见行动文案按证据选择，最多显示三条：

- **先不要急着付款。**
- **请核对对方的真实身份。**
- **请通过官方电话或官网核实。**
- **宣传内容不要只听销售人员说明。**
- **涉及用药，请先问医生或药师。**

### 3. 红色：请先停一下

| 项目 | 页面文案 |
|---|---|
| 卡片标题 | **请先停一下** |
| 简短说明 | 材料中出现了需要立即警惕的情况。 |
| 行动提示 | 请先停止相关操作，并请家人一起核对。 |
| 主按钮 | **查看现在该做什么** |
| 家属简报状态 | 按实际状态显示：**简报已自动生成并推送** / **简报已生成，请先绑定家属联系人** / **简报已生成，但推送失败，请检查联系方式** |

红色风险不显示“生成家属简报”按钮，系统自动生成家属简报。已有授权且有效的家属联系方式时自动推送；没有授权联系人时不发送并提示绑定；联系方式无效时提示推送失败。绿色和黄色仍由用户主动选择是否生成。

按实际证据选择立即行动，不得全部堆叠：

| 触发证据 | 立即行动文案 |
|---|---|
| 索要验证码 | **不要提供短信验证码。** |
| 要求私人转账 | **先不要向个人账户转账。** |
| 陌生链接或远程控制 | **不要点击链接，也不要允许远程操作手机。** |
| 诱导停药或替代治疗 | **不要自行停药或换药，请马上联系医生或药师。** |
| 冒充官方要求付款 | **先通过官方电话核实，不要使用对方提供的号码。** |
| 恐吓、催促或要求保密 | **先暂停沟通，把情况告诉家人。** |
| 已付款且对方失联 | **保存付款和聊天记录，尽快联系支付平台或警方咨询。** |

## 三、无法判断状态

### 信息不足

- 标题：**目前信息还不够**
- 说明：暂时无法判断，请补充完整材料。
- 补拍提示：请拍清楚名称、宣传内容、付款要求和对方身份信息。
- 主按钮：**补充材料**

### 图片模糊

- 标题：**图片有些模糊**
- 说明：没有看清关键文字，请在光线明亮的地方重新拍摄。
- 主按钮：**重新拍照**

### 内容互相矛盾

- 标题：**发现信息不一致**
- 说明：不同材料中的名称、身份或说法不一致，暂时不能下结论。
- 主按钮：**查看不一致内容**

### 没有直接证据

- 标题：**暂时不能确定**
- 说明：目前没有足够的原文证据，建议先核实，不要急着付款或作决定。
- 主按钮：**查看核实方法**

## 四、防骗结果页文案结构

### 第一屏

按顺序显示：

1. 风险等级标题；
2. 一句话说明；
3. 红色时显示“现在该做什么”；
4. 最多三条关键证据；
5. 一个主按钮。

### 关键证据

- 区域标题：**我们看到了这些内容**
- 原文格式：**材料中写着：“{原文证据}”**
- 解释格式：**需要注意：{简短原因}**
- 来源格式：**来自第 {图片序号} 张图片**
- 无法辨认：**这段文字没有看清，请对照原图。**

每条证据只解释一个风险点，不把多个结论写在一个长段落中。

### 详细风险

折叠入口：**查看详细分析**

展开后按实际存在的风险显示：

- **对方身份**；
- **宣传说法**；
- **付款和退款**；
- **催促和情绪施压**。

没有相关证据的栏目不显示。

### 核实方法

- 区域标题：**可以这样核实**
- 身份核实：**通过机构官网或官方电话核对，不使用对方提供的联系方式。**
- 产品核实：**核对包装上的批准、注册或备案信息。**
- 付款核实：**确认收款方是否与合同或正规订单一致。**
- 医疗核实：**涉及停药、换药或疗效，请咨询医生或药师。**

### 保存证据

- 区域标题：**请保存这些材料**
- 提示：请保存聊天记录、宣传原文、订单、付款记录、收款账户和退款规则。
- 按钮：**查看证据清单**

## 五、药品结果页风险文案

药品页不使用防骗页的绿、黄、红结论直接表示药品安全性，改用核对状态。

### 信息已核对

- 标题：**信息已核对**
- 说明：药名、规格等关键信息能够与目录记录对应。

### 有信息要确认

- 标题：**有信息要确认**
- 说明：有些文字没有看清，或材料与目录信息不一致。
- 按钮：**查看要确认的内容**

### 材料不完整

- 标题：**材料没有拍全**
- 说明：用法、禁忌或注意事项可能不完整。
- 按钮：**补拍材料**

### 发现用药相关高风险内容

- 诱导停药：**不要自行停药，请先联系医生或药师。**
- 诱导换药：**不要自行换药，请先联系医生或药师。**
- 用量不一致：**材料中的用量不一致，请以医生处方为准并再次确认。**
- 药名或规格模糊：**药名或规格没有看清，请勿按识别结果确定用量。**

## 六、家属简报中的风险文案

- 页面标题：**给家人的情况说明**
- 最高风险：**目前最需要关注：{风险标题}**
- 发生情况：**材料中出现了：{事实摘要}**
- 直接证据：**原文写着：“{证据原文}”**
- 建议行动：**建议家人先做：{行动}**
- 信息不足：**还有一些信息没有确认，请和老人一起核对。**
- 转发按钮：**确认后转发给家人**

简报只写材料事实、风险依据和下一步行动，不写责备老人或评价其判断能力的内容。

## 七、通用按钮文案

| 使用目的 | 推荐文案 |
|---|---|
| 查看风险 | 查看分析结果 |
| 查看立即行动 | 查看现在该做什么 |
| 进一步核实 | 查看核实方法 |
| 补充图片 | 补充材料 |
| 图片重拍 | 重新拍照 |
| 家人协助 | 请家里人一起看 |
| 生成摘要 | 生成家属简报 |
| 返回起点 | 返回首页 |

避免使用“继续处理”“执行策略”“风险处置”“验证主体”等专业按钮名称。

## 八、A的展示验收要求

- 风险标题无需滚动即可看到。
- 红色状态的立即行动必须在详细解释之前。
- 关键证据最多三条，更多内容折叠。
- 颜色之外必须有图标和文字。
- 手机端不使用横向表格。
- 一屏只有一个主要操作。
- 所有风险结论都能查看材料原文和来源。
- 绿色结果不得出现“安全”“放心购买”“已经确认是真药”等绝对表述。
- 绿色和黄色不得默认生成或发送家属简报；红色风险自动生成，并仅在存在已授权且有效的家属联系方式时自动推送。
