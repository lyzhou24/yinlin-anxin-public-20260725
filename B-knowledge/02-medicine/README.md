# 药品知识域

本目录负责药品材料提取、目录字段核对、引用格式和页面文案，不提供个体诊疗或用药决策。

## 重点文件

- 字段和来源结构：[`docs/药品知识库引用格式.md`](./docs/药品知识库引用格式.md)
- 页面展示文案：[`docs/药品字段文案.md`](./docs/药品字段文案.md)
- UI字段关系：[`docs/药品UI架构图.md`](./docs/药品UI架构图.md)
- 说明书处理规范：[`docs/药品说明书结构规范.md`](./docs/药品说明书结构规范.md)
- 药品资料来源：[`data/source/资料来源清单.md`](./data/source/资料来源清单.md)

## 目录职责

| 目录 | 内容 | 使用边界 |
|---|---|---|
| `docs/` | 引用、字段、UI和说明书规范 | 作为维护与接口对齐标准 |
| `data/source/` | 官方原始PDF、医保编码分片和原始说明书 | 只读留档，不直接改写 |
| `data/processed/` | 西药、中成药聚合结果和清洗后说明书 | 不得补写原始来源没有的用药信息 |
| `data/results/` | 编码分析和匹配结果 | 属于中间结果，不等于官方结论 |
| `templates/` | 说明书知识录入模板 | 新增数据时复制使用 |
| `scripts/` | 数据处理脚本 | 输入、输出路径变化后必须重新验证 |

## 关键边界

1. `material_value`只来自用户材料或人工确认。
2. `catalog_value`只来自对应目录或官方记录。
3. 目录值不得悄悄覆盖材料值。
4. 目录不得补写剂量、频次、禁忌、不良反应或疗效。
5. 医保药品编码匹配不代表医保报销资格、报销范围或报销比例。
6. 药品真实性应组合核验药名、批准文号、规格、企业、批号、有效期和追溯信息。
