# 药品目录数据

本目录保存从医保药品编码数据整理出的药品注册、规格、企业、批准文号及医保编码信息。

```text
catalog/
├─ western/          西药
└─ chinese_patent/   中成药
```

每类均包含：

- 全量记录：保留每条医保药品编码明细；
- 按批准产品聚合：用于按批准文号、产品和规格检索；
- 按注册名称聚合：用于按药品名称检索。

这些文件是产品身份与医保编码目录，不是药品说明书。不得从目录字段推断成分、适应症、用法用量、禁忌、不良反应或药物相互作用。

推荐关联顺序：批准文号 → 通用名称与规格 → 上市许可持有人。出现冲突时进入人工确认，不自动合并。
