# 药品字段文案（适老化精简版）

> 交付对象：成员A（产品、UI与网页前端）  
> 字段依据：`catalog` 实际数据表头，以及药盒、说明书 OCR 可提取字段。  
> 核心要求：一屏只做一件事；首屏只放最重要的信息；短句、大字、少按钮。

配套页面结构见[药品UI架构图.md](./药品UI架构图.md)。本文件中的模块顺序与A现有的 `/medicine` 页面架构一致。

## 一、页面展示原则

- 首屏使用一张“大字用药卡”，最多显示 4 个内容块：药名与规格、主要用途、材料上的用法、重要提醒。
- 每项默认只显示 1—3 行，长内容点击“查看全部”。
- 医保编码、本位码、企业、包装材质等不放首屏。
- 不同时展示所有说明书章节，按“常用信息”和“更多信息”分层。
- 每个页面只保留一个醒目的主按钮。
- 不使用“注册剂型”“源数据状态”等专业词直接面对老人。
- 缺少信息时说清楚“没拍到”或“没看清”，不堆叠多个警告。

## 二、药品结果页第一屏：大字用药卡

### 页面标题

**药品结果**

辅助说明：请先看看药名和规格对不对。

### 顶部状态

顶部状态只显示一行，并同时使用图标和文字：

- **信息已核对**：关键信息能够与目录记录对应；
- **有信息要确认**：存在模糊、缺失或不一致；
- **材料不完整**：说明书缺页或关键区域没有拍到。

不使用“绿色安全”“没有风险”等绝对结论。

### 首屏内容

#### 1. 药名与规格

标题：**药品名称**

内容：`{药品名称}`

有商品名时用小一号文字显示：`也叫：{商品名称}`

没看清时：**药名没看清，请重新拍一下药盒正面。**

规格紧跟药名显示：`规格：{实际规格或OCR规格}`

没看清时：**规格没看清，请看药盒上的“规格”。**

#### 2. 这个药是做什么的

标题：**这个药是做什么的**

内容：来自说明书“适应症或功能主治”的简短解释，最多显示 2—3 行。

没有说明书内容时：**这次材料里没有看到用途说明。**

#### 3. 材料上写的用法

标题：**材料上写的是**

内容按三行以内展示，只填写材料明确出现的内容：

- **每次：** `{用量}`
- **每天：** `{次数}`
- **时间：** `{饭前／饭后／睡前等}`

没拍到时：**这张图片上没有看到用法。**

固定提醒：**请按医生或药师交代的方法使用。**

#### 4. 重要提醒

标题：**请注意**

内容：最多显示 3 条最重要的禁忌或注意事项，每条只写一个意思。

材料不全时：**说明书没有拍全，注意事项可能不完整。**

首屏只保留展开入口：**查看详细信息**。确认操作放入“需要确认”模块，不额外占用首屏。

## 三、药品结果页第二屏：详细信息

第二屏默认收起，点击 **查看详细信息** 后显示，顺序如下：

1. **不能使用的情况**；
2. **可能出现的不舒服**；
3. **怎样保存**；
4. **药品身份信息**；
5. **信息来源**。

### 身份核对结果

核对范围来自药盒 OCR 与 `catalog`：药品名称、批准文号、剂型、规格和企业。

### 已对应

- 标题：**药品信息已对上**
- 说明：药名、规格等信息与目录记录一致。

### 还需确认

- 标题：**有些信息还要确认**
- 说明：请对照药盒，看看药名、规格和批准文号。
- 按钮：**查看哪里不一样**

### 找到多个产品

- 标题：**找到了几个同名药品**
- 说明：请按药盒上的规格和批准文号选择。
- 每张候选卡只显示：药名、规格、企业、批准文号。

### 没找到记录

- 标题：**暂时没有找到对应记录**
- 说明：可能是图片不清楚，也可能是当前目录没有收录。
- 按钮：**重新拍照**

> 不向老人显示“匹配失败”“字段冲突”“真药”“假药”等容易误解的结论。

## 四、详细信息中的药品身份

身份信息继续分为常用字段和“查看编号和包装信息”，不把所有字段铺在同一页。

### 1. 药品是什么

默认显示：

- **药品名称**：目录“注册名称”或 OCR 药品名称；
- **剂型**：优先显示目录“实际剂型”；
- **规格**：优先显示目录“实际规格”；
- **批准文号**：目录与 OCR 核对后的批准文号；
- **生产企业**：优先显示药盒对应产品的“药品企业”。

展开按钮：**查看编号和包装信息**

展开后才显示：医保药品代码、药品本位码、注册剂型、注册规格、上市药品持有人、包装材质、最小包装数量和包装单位。

面向老人时使用以下名称：

| catalog 字段 | 页面名称 |
|---|---|
| 注册名称 | 药品名称 |
| 实际剂型 | 剂型 |
| 实际规格 | 规格 |
| 药品企业 | 生产企业 |
| 上市药品持有人 | 药品持有人 |
| 最小包装数量 + 最小制剂单位 | 每盒有多少 |
| 最小包装单位 | 包装单位 |
| 源数据状态 | 目录状态 |

`原始序号`、`来源文件`和`聚合原始记录数`不展示给老人，仅供系统追溯。

### 2. 详细用法

按以下顺序显示：

1. **材料上写的用法**：来自药盒、处方或用药清单 OCR；
2. **说明书上的用法**：来自说明书“用法用量”章节；
3. **适合哪些情况**：来自“适应症或功能主治”章节。

两种用法必须分开，不能混成一段。

固定提醒：**如果两处写法不一样，请先问医生或药师。**

### 3. 安全信息

默认只显示：

- **不能使用的情况**：说明书“禁忌”；
- **使用前要注意**：说明书“注意事项”；
- **可能出现的不舒服**：说明书“不良反应”；
- **老年人用药**：说明书“老年用药”。

每个栏目默认最多显示 3 条，点击 **查看全部** 展开原文。

以下内容放在 **其他人群和同用提醒** 中：

- 孕期和哺乳期用药；
- 儿童用药；
- 与其他药物同用要注意；
- 使用过量。

### 4. 保存和日期

只显示图片或说明书中明确识别到的内容：

- **怎样保存**：贮藏；
- **有效期**：说明书有效期；
- **有效期至**：药盒喷码；
- **生产日期**：药盒喷码；
- **产品批号**：药盒喷码。

日期看不清时统一显示：**日期没看清，请以药盒上的文字为准。**

## 五、说明书更多内容

临床试验、药理毒理、药代动力学、性状、成分、包装和执行标准不在常用页面展开。

统一放在：**说明书其他内容**

入口说明：这里是说明书中的专业内容，需要时可以查看。

说明书没有拍全时，只显示一次提醒：

> 说明书没有拍全，下面的信息可能不完整。

按钮：**补拍说明书**

## 六、药品结果页第三屏：需要确认

同一页面最多显示一条确认提醒，优先级为：药名 → 规格 → 批准文号 → 用法 → 日期。

| 情况 | 显示文案 |
|---|---|
| 药名模糊 | 药名没看清，请拍清楚药盒正面。 |
| 规格模糊 | 规格没看清，请拍清楚“规格”一栏。 |
| 批准文号模糊 | 批准文号没看清，请拍清楚药盒背面。 |
| 用量或次数模糊 | 用法没有看清，请不要按识别结果改变用量。 |
| 说明书缺页 | 说明书没有拍全，请补拍缺少的页面。 |
| 日期模糊 | 日期没看清，请以药盒上的文字为准。 |

主按钮统一使用：**重新拍照**

如果只是让用户确认候选文字，按钮使用：**是这个药**；次按钮使用：**不是这个药**。

## 七、详细信息中的来源

老人页面只显示简短来源：

- **来自您上传的药盒**
- **来自您上传的说明书**
- **来自医保药品编码数据**

页面入口：**查看信息来源**

点击后才显示图片编号、说明书页码、目录来源文件和更新时间等追溯信息。

医保药品编码数据仅用于核对药名、剂型、规格、企业、批准文号和药品编码等身份信息。编码匹配不代表该药属于医保报销范围，也不代表该药可以报销或具有特定报销比例。如需核对最新编码，请访问国家医保信息业务编码标准数据库：`https://code.nhsa.gov.cn/`。

## 八、页面状态文案

- 正在识别：**正在看图片，请稍等……**
- 正在核对：**正在核对药品信息……**
- 图片不清楚：**图片有些模糊，请重新拍一张。**
- 没有识别到文字：**没有看清文字，请在光线明亮的地方重拍。**
- 暂无结果：**暂时没有可显示的药品信息。**

## 九、页面底部操作

- 绿色或黄色：主按钮显示**生成家属简报**，跳转`/family`；
- 红色：不显示生成按钮；自动生成简报，并按实际状态显示**简报已自动生成并推送**、**请先绑定家属联系人**或**推送失败，请检查联系方式**；
- 次操作：**重新上传**，返回 `/upload`；
- 文字链接：**返回首页**，返回 `/`。

若家属简报功能当前未上线，绿色和黄色隐藏主按钮，不显示不可点击的占位按钮；红色自动生成、授权联系人查询、推送状态回写和页面提示必须同时上线。

## 十、前端取值规则

- 药名：OCR 药名为用户确认对象，`注册名称`为目录核对值。
- 剂型：首选`实际剂型`，没有时使用`注册剂型`或 OCR 剂型。
- 规格：首选与批准文号对应的`实际规格`，没有时使用`注册规格`或 OCR 规格。
- 包装数量：组合`最小包装数量 + 最小制剂单位 + 最小包装单位`，例如“每盒24片”。
- 多个目录记录不得直接展示带 `|` 的聚合值，必须拆成候选卡片。
- OCR 和目录不一致时并排展示，不自动覆盖。
- 长段说明书内容必须分条、折叠，不能整段铺满页面。

## 十一、固定安全提示

结果页底部只保留这一条：

> 这些信息用来帮助您看懂药品，不能代替医生或药师。请不要自己停药、换药或改变用量。
