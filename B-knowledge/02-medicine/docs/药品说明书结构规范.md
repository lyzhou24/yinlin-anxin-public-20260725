# 药品说明书结构规范

## 一、用途

本规范用于将药品说明书 OCR 原文整理为可检索、可追溯的知识库内容。OCR 只负责文字识别；章节识别、跨页合并、字段提取和缺失检查在说明书结构化环节完成。

说明书知识不得与医保编码目录混为一类。两者可通过“批准文号、通用名称、规格、上市许可持有人”等字段关联，但不能互相补全未出现的信息。

## 二、目录约定

```text
instructions/
├─ 药品说明书结构规范.md
├─ 药品说明书知识库模板.csv
├─ source/                  原始PDF或图片，只读留档
└─ data/                    清洗后的说明书知识文档
```

## 三、标准章节

每份清洗后的说明书文档按以下顺序组织；材料没有的章节保留标题并标记“原材料未提供”，不得根据常识补全。

1. 基本信息
2. 成分
3. 性状
4. 适应症或功能主治
5. 规格
6. 用法用量
7. 不良反应
8. 禁忌
9. 注意事项
10. 孕妇及哺乳期妇女用药
11. 儿童用药
12. 老年用药
13. 药物相互作用
14. 药物过量
15. 临床试验
16. 药理毒理
17. 药代动力学
18. 贮藏
19. 包装
20. 有效期
21. 执行标准
22. 批准文号
23. 上市许可持有人
24. 生产企业
25. 来源与版本信息

## 四、字段规则

| 字段 | 录入要求 |
|---|---|
| 通用名称 | 以说明书标题或批准信息为准；模糊时留空 |
| 商品名称 | 原文存在时填写，不存在则留空 |
| 批准文号 | 保留原始格式，用作与目录数据关联的首选键 |
| 剂型、规格 | 忠实转录，不自行换算或标准化剂量 |
| 用法用量 | 保留适用人群、给药途径、频次、疗程等限定词 |
| 禁忌、注意事项 | 不删减“禁用、慎用、遵医嘱”等关键限制 |
| 特殊人群用药 | 分别记录孕妇、儿童和老年人内容，不合并推断 |
| 来源 | 记录原文件名、页码或图片编号 |
| 版本信息 | 记录说明书核准/修改日期；无法确认则留空 |

## 五、OCR与跨页处理

- 保留原始 OCR 文本，不直接覆盖。
- 页眉、页脚、页码和重复标题可在清洗层去重，但不得删除正文。
- 章节跨页时按标题和语义连续性合并，并保存原页码范围。
- 剂量、频次、规格、批准文号等高风险字段若字符模糊，标记 `需要人工确认`。
- 同一药品存在多个说明书版本时分别保存，不覆盖旧版本。
- 图片缺页或章节突然中断时标记 `可能缺页`。

## 六、知识文档命名

```text
通用名称__规格__批准文号__版本日期.md
```

文件名中的非法字符替换为下划线。版本日期未知时使用 `日期待确认`。

## 七、安全边界

- 不依据医保目录推断说明书适应症、用法用量或禁忌。
- 不把宣传材料中的功效表述写入说明书知识。
- 不输出诊断、推荐药品、停药、换药或改量建议。
- 说明书信息仅用于解释和核对，个体用药应由医生或药师确认。
