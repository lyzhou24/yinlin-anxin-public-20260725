# 防骗知识域

本目录维护健康消费和涉老场景的正式防骗规则、来源映射、同义词和药品真实性核验规则。

## 重点文件

- 正式防骗主表：**[`data/防骗知识库.csv`](./data/防骗知识库.csv)**
- 药品真实性规则：[`data/药品真实性核验规则.csv`](./data/药品真实性核验规则.csv)
- OCR和检索同义词：[`data/风险话术同义词.csv`](./data/风险话术同义词.csv)
- 录入字段规范：[`docs/防骗字段与录入规范.md`](./docs/防骗字段与录入规范.md)
- 来源清单：[`sources/防骗资料来源清单.csv`](./sources/防骗资料来源清单.csv)
- 来源使用映射：[`sources/防骗来源使用映射.csv`](./sources/防骗来源使用映射.csv)

## 目录职责

| 目录 | 内容 | 不可用于 |
|---|---|---|
| `data/` | 正式规则、同义词、真实性规则、类型目录和案例知识卡 | 脱离上下文直接定性诈骗或违法 |
| `docs/` | 字段规范、建设方案、案例结构和目录说明 | 替代正式规则主表 |
| `sources/` | 来源元数据和知识使用映射 | 把未核验来源当作正式规则依据 |
| `templates/` | 防骗规则和案例空白模板 | 直接导入Coze |

原始网页及附件已经移至[`../archive/source-pages/fraud/`](../archive/source-pages/fraud/)，仅用于来源复核。

## 维护流程

```text
来源登记
→ 在data/维护正式规则
→ 检查来源编号和字段
→ 同步生成04-workflow/coze-import文件
→ 使用05-tests标准样本回归测试
```

## 关键边界

1. 正式风险类型只使用身份、宣传、交易和情绪操控四类。
2. `product_authenticity`只由药品真实性核验流程生成。
3. 每条Risk证据都应返回用户材料位置和`FRAUD-SRC-xxx`知识来源。
4. 信息不足时不调用Risk，不返回风险结果，不显示风险徽章。
5. green表示“暂未发现明显风险”，不得显示为“安全”或“真药”。
6. 单个关键词、相似案例或单个药品字段不能独立构成诈骗、违法或真假药结论。
