# CASE-FRAUD-001 免费礼品引流至私域直播

- 案例编号：CASE-FRAUD-001
- 场景类别：健康消费 / 私域直播
- 目标人群：参加免费活动、健康讲座或私域直播的老年人及其家属。
- 引流方式：免费鸡蛋、社区义诊或老年福利活动。
- 建立信任方式：引导加微信、入群，连续收看养生课程和专家咨询。
- 核心话术或行为：把普通食品或保健食品宣传为可治疗高血压、癌症等疾病。
- 促成交易方式：直播下单或转到线下门店消费。
- 阻止核验方式：封闭直播、播完关闭、群内信息难以公开检索。
- 风险信号：免费引流；私域场景；假专家；疾病治疗承诺；高价产品。
- 可复用结论：免费活动与入群、假身份、虚假疗效和付款连续出现时，应显著提高风险。
- 建议行动：暂停购买，保存直播和群聊，核验产品、专家和经营主体。
- 输出限制：相似链条不等于已经构成诈骗或违法。
- 来源编号：FRAUD-SRC-006；FRAUD-SRC-009

# CASE-FRAUD-002 普通食品包装成治疗产品

- 案例编号：CASE-FRAUD-002
- 场景类别：健康消费 / 虚假疗效
- 目标人群：患有慢性病、购买保健食品的老年人及其家属。
- 引流方式：签到、授课、视频讲解或门店交流会。
- 建立信任方式：反复讲解慢性病危害并展示所谓用户见证。
- 核心话术或行为：宣称普通食品可降三高、治疗冠心病或改善多种疾病。
- 促成交易方式：现场购买或会员价成交。
- 风险信号：产品身份冲突；治疗承诺；会议营销；群体见证。
- 可复用结论：产品标签显示普通食品而宣传内容包含疾病治疗，是直接高危宣传信号。
- 建议行动：不要替代正规治疗，核对标签、批准信息和经营许可。
- 输出限制：系统只提示风险，行政违法结论由监管部门作出。
- 来源编号：FRAUD-SRC-007

- 目标人群：参加免费体检、义诊或健康咨询的老年人。
- 引流方式：免费体检、健康咨询或义诊。
- 建立信任方式：所谓专家现场看病，利用检测报告制造专业感。

- 阻止核验方式：用病情紧迫阻止老人离场复查。
- 风险信号：免费检测；假专家；夸大病情；特效药；立即付款。
- 可复用结论：未经正规医疗机构复核的异常报告与指定产品销售绑定时，应暂停购买。

# CASE-FRAUD-015 虚构批准文号和生产企业销售所谓中药

- 案例编号：CASE-FRAUD-015
- 场景类别：药品真实性 / 老年健康消费
- 目标人群：通过非正规渠道购买所谓中药或特效药的老年人。
- 引流方式：面向老年人宣传能够治疗常见慢性病或疼痛的所谓中药产品。
- 建立信任方式：在包装和材料中使用药品名称、批准文号、生产企业及医生身份等专业信息。
- 核心话术或行为：相关批准文号、生产企业或医生身份无法在官方记录中对应，办案机关进一步结合药监查询、司法材料和鉴定核实。
- 促成交易方式：以药品疗效和专业身份推动老人购买并服用。
- 阻止核验方式：使用看似完整的包装字段和专业名称降低老人继续查询的意愿。
- 风险信号：批准文号无记录；生产企业不对应；专业身份无法核验；面向老人宣称治疗。
- 可复用结论：包装上出现批准文号和生产企业不等于实物已经核验，应把编号、药名、持有人、生产企业、规格和渠道逐项比对。
- 建议行动：暂停使用和购买，保存包装、说明书、订单及查询截图，并向药师或药品监管部门核验。
- 输出限制：相似字段异常只能提示高风险，不能代替主管部门调查和检验直接认定假药。
- 来源编号：FRAUD-SRC-045

# CASE-FRAUD-016 非药品许可信息包装成治病药品

- 案例编号：CASE-FRAUD-016
- 场景类别：药品真实性 / 非药品冒充药品
- 目标人群：接触非药品许可产品和治病宣传的老年慢性病患者。
- 引流方式：向有风湿疼痛等健康需求的老年消费者推销所谓丸剂产品。
- 建立信任方式：产品名称和说明材料采用类似药品的形式，并通过销售场所或人员背书。
- 核心话术或行为：包装标示卫食证字号，但说明书和销售宣传声称能够治疗并治愈风湿病。
- 促成交易方式：把非药品按具有治疗作用的药品销售并收取货款。
- 阻止核验方式：利用消费者不熟悉批准文号和不同产品编号体系的差异。
- 风险信号：非药品许可编号；疾病治疗承诺；产品类别与宣传用途冲突；面向老人销售。
- 可复用结论：先判断编号对应的产品类别，再判断宣传是否把食品或其他产品包装成药品，不能只看产品名称中是否带“丸”“胶囊”。
- 建议行动：不要按药品购买或服用，保存包装六面、编号、说明书、销售聊天和付款凭证，并通过国家药监局及医生药师核验。
- 输出限制：系统只提示类别冲突和高风险，是否属于假药或违法由药品监管、司法机关结合实物和案件事实认定。
