# 防骗字段与录入规范

## 冻结字段

| 字段 | 填写要求 |
|---|---|
| 场景 | 如讲座、聊天推销、直播、电话、付款或退款 |
| 原始话术 | 保留能够支持风险判断的原句，不改写成结论 |
| 风险类型 | 身份、宣传、交易、情绪操控四选一；多种风险拆行 |
| 风险等级 | 绿色、黄色或红色 |
| 风险原因 | 结合上下文解释，不得只根据单个关键词判断 |
| 建议停止操作 | 明确写出先停止付款、提供验证码、点击链接或自行停药等操作 |
| 核验方法 | 写明正规核验对象、渠道和信息 |
| 证据保存 | 列出聊天、订单、付款、账户、承诺和退款规则等证据 |
| 来源 | 填写来源清单中的唯一编号 |

## 三级风险标准

- 绿色：暂未发现明显风险，提供信息解释和来源提醒；
- 黄色：身份或宣传信息不清，需要向家属、医生、药师或正规机构核验；
- 红色：出现索要验证码、私人转账、诱导停药、冒充官方、恐吓或要求隐瞒家属等行为。

## 禁止事项

- 不直接认定对方实施诈骗或违法；
- 不使用恐吓、羞辱或责备语言；
- 不把单个营销词自动判定为高风险；
- 不在缺少原文证据时输出确定性结论；
- 涉及停药时，只能提示不要自行停药并向医生或药师确认。
