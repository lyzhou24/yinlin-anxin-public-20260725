# 防骗案例结构规范

一张案例卡只描述一条完整的诈骗或高风险营销链条，使用以下固定结构：

```text
案例编号：
案例名称：
场景类别：
目标人群：
引流方式：
建立信任方式：
核心话术或行为：
促成交易方式：
阻止核验方式：
风险信号：
可复用结论：
建议行动：
输出限制：
来源编号：
```

## 录入要求

1. 官方明确认定的案件事实和项目归纳必须分开表述。
2. 核心话术应保留来源中的短句；无法定位原句时只描述行为，不补写对白。
3. 案例中的姓名、机构和金额仅在有助于风险识别时保留。
4. “可复用结论”只能说明风险组合，不能把相似材料直接认定为同类犯罪。
5. 建议行动必须对应当前可停止的操作、正规核验渠道和应保存证据。
6. 输出限制固定包含：相似案例不等于已经构成诈骗或违法，仍需结合完整材料和主管部门结论。
