# Coze导入说明

## 药品知识库

第一版药品知识库使用`Coze药品知识库导入.csv`，由以下两个按批准产品聚合的数据文件合并生成：

- `../../02-medicine/data/processed/western/西药_按批准产品聚合.csv`；
- `../../02-medicine/data/processed/chinese-patent/中成药_按批准产品聚合.csv`。

导入表共16,460条，其中西药7,230条、中成药9,230条。建议在Coze中使用表格知识库并按行导入，将以下字段设为主要检索字段：

- `注册名称`；
- `商品名称（全部）`；
- `批准文号（全部）`；
- `药品企业（全部）`；
- `上市药品持有人（全部）`；
- `医保药品代码（全部）`；
- `药品本位码（全部）`。

每条记录固定标记来源编号`SRC-002`，页面简称为“来自医保药品编码数据”。该知识库只用于药品名称、剂型、规格、企业、批准文号和医保药品代码等基础字段匹配；编码匹配不代表属于医保报销范围、可以报销或具有特定报销比例；不得用于补写用法用量、禁忌、不良反应或疗效。

导入完成后，由成员C记录实际知识库ID，并使用`../../05-tests/防骗标准测试样本.csv`中的药品、多药和药品与保健品对照样本进行联调。

## 防骗知识库

`Coze防骗知识库导入.csv`是`../../03-fraud/data/防骗知识库.csv`的机械副本，字段和行顺序必须保持一致。

建议在Coze中使用表格知识库并按行切片，将“场景”“原始话术”“风险类型”设为检索字段。导入后必须用`../../05-tests/防骗标准测试样本.csv`检查召回和安全边界。

## 药品真实性核验知识库

`Coze药品真实性核验导入.csv`是`../../03-fraud/data/药品真实性核验规则.csv`的机械副本，供材料分类后对药品包装OCR字段进行结构化比对。建议把“药品批准文号或注册证号”“药品通用名称”“上市许可持有人”“生产企业”“剂型和规格”作为组合核验字段，不得根据单个字段直接输出“假药”结论。
