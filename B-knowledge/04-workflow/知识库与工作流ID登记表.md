# 知识库与工作流ID登记表

## 一、用途

本表用于登记Coze中实际创建的知识库、工作流及其版本，供成员A、B、C联调和问题追踪。ID只能在对象实际创建后填写，不得预估、复用其他环境ID或把文件名当作ID。

维护负责人：成员C填写平台ID和发布信息，成员B核对导入文件及知识内容，成员A核对接口绑定关系。

## 二、环境说明

| 项目 | 当前值 |

| 平台 | Coze |
| 项目/空间名称 | 待成员C填写 |
| 环境 | 开发环境，待成员C确认 |
| 登记表更新时间 | 待填写 |
| 最后更新人 | 待填写 |

不同环境必须分别登记，不得把开发、测试和正式环境ID写在同一单元格中。

## 六、每次导入或发布必须记录

1. 实际平台ID、环境和版本号；
2. 使用的导入文件及其记录数；
3. 导入或发布时间；
4. 操作人；
5. 对应接口或页面；
6. 本次变更内容；
7. 验证使用的测试样本编号；
8. 失败问题及回归结果。

只有完成ID登记、接口绑定和标准样本验证后，状态才能改为“已验证”或“已发布”。
