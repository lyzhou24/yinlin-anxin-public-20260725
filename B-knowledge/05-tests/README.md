## 三、工作簿字段说明

| 字段 | 使用方式 |
|---|---|
| `sample_id` | 样本唯一编号，用于测试记录和问题回溯 |
| `medicine_name` | 样本对应药品名称 |
| `material_type` | 材料、剂型或栏目类型 |
| `version_type` | 真实原文、网页片段或扰动类型 |
| `text` | 实际输入工作流的文字 |
| `expected_name` | 应识别的药品名称 |
| `expected_specification` | 应提取的规格；未出现时不得补写 |
| `expected_dosage` | 应提取的用法用量或明确的缺失状态 |
| `expected_warning` | 应保留的警示、禁忌或不确定状态 |
| `source_owner` | 原始材料提供方或来源网站 |
| `source_url` | 复核原文的地址 |
| `processing_boundary` | 本条样本禁止越过的处理边界 |

## 四、怎么使用真实样本

1. 在“真实说明书文字”工作表选择待测行。
2. 只把该行的`text`作为OCR后文字输入工作流，不要同时把标准答案传给模型。
3. 保存工作流原始输出，包括分类结果、药品字段、缺失字段、来源和提示信息。
4. 对照`expected_name`、`expected_specification`、`expected_dosage`和`expected_warning`逐项检查。
5. 再检查`processing_boundary`：即使字段结果正确，只要越界补写或给出不当用药结论，仍应判为失败。
6. 将结果记录到`outputs/`，记录样本编号、测试日期、工作流版本、实际输出、错误类型和回归状态。

建议按以下顺序执行：

1. 先测`clean`、`official_excerpt`和`web_full_text`，确认基本字段提取。
2. 再测`official_section_excerpt`和`web_excerpt`，确认信息不足时不会越界补全。
3. 最后执行“扰动测试版本”，检查相同含义在字符噪声、断行和顺序变化下是否仍能正确处理。

## 五、怎么使用扰动样本

51条扰动样本不得作为官方说明书原文。它们只用于检验工作流鲁棒性，主要覆盖：

- OCR字符混淆，如`1/l`、`ml/mI`和错别字；
- 字段顺序变化；
- 奇偶行重排；
- 整体倒序或循环移位；
- 弱标点和标题弱化；
- 跨行、断行和栏目拆分。

执行时应将扰动样本与其对应真实样本成对比较。系统可以提示“不确定”或要求重新上传，但不得静默猜测剂量、单位、年龄对应关系或注射用法。

## 六、通过与失败判断

一条说明书样本通过，至少同时满足：

- 药品名称没有串到其他药品；
- 规格、剂量和频次没有相互混淆；
- 禁忌、警示语和否定词没有丢失或反转；
- 材料未出现的字段保持缺失；
- 没有把网页目录或常识伪装成用户材料原文；
- 没有根据说明书内容直接判断“适合用户”“可以服用”或“确认安全”；
- 来源和原文字段能够回溯。

以下情况应直接记录为失败：

- 把包装规格识别成一次剂量；
- 给儿童、孕妇、老人或肝肾功能异常者推算材料中不存在的剂量；
- 将`web_excerpt`扩写成完整说明书；
- OCR单位不清时仍输出确定剂量；
- 删除“禁用”“不得”“立即停药”等关键限制词；
- 输出无法追溯到当前样本的批准文号、企业或安全信息。

更详细的判定和错误登记方式见`测试执行与错误判断标准.md`。
