# 药品、普通食品、保健食品批准文号标准说明

> 版本日期：2026-07-18  
> 用途：内部测试、OCR结果校验、产品分类和防骗提示。  
> 注意：编号“格式正确”只代表形式初步符合规则，不代表产品真实、有效或与当前包装一致；最终必须到对应监管部门官方数据库核验。

## 一、快速区分

| 类别 | 包装上重点编号 | 常见格式 | 编号性质 |
|---|---|---|---|
| 药品 | 药品批准文号 | `国药准字H20231234`、`国药准字Z20231234`、`国药准字S20231234` | 药品品种的上市批准编号 |
| 普通食品 | 食品生产许可证编号 | `SC`＋14位数字 | 生产者的生产许可编号，不是单个食品的产品批准文号 |
| 保健食品（注册制） | 保健食品注册号 | `国食健注G20231234`、`国食健注J20231234` | 保健食品产品注册号 |
| 保健食品（备案制） | 保健食品备案号 | `食健备G2023XX123456`、`食健备J202300123456` | 保健食品产品备案号 |

核心判断：

- `国药准字……`：药品。
- `国食健注……`或`食健备……`：保健食品产品注册/备案信息。
- `SC……`：食品生产许可信息，不能仅凭它把产品判断为保健食品，更不能判断为药品。
- 执行标准号（如 `GB`、`GB/T`、`Q/企业代号`）、条形码、专利号、商标注册号、追溯码、医保编码都不是产品批准文号。

## 二、药品批准文号

### 2.1 现行基本格式

按照《药品注册管理办法》第一百二十三条：

| 生产情形 | 格式 |
|---|---|
| 境内生产 | `国药准字H（Z、S）＋4位年份＋4位顺序号` |
| 中国香港、澳门和台湾地区生产 | `国药准字H（Z、S）C＋4位年份＋4位顺序号` |
| 境外生产 | `国药准字H（Z、S）J＋4位年份＋4位顺序号` |

字母含义：

- `H`：化学药；
- `Z`：中药；
- `S`：生物制品；
- `C`：中国香港、澳门和台湾地区生产；
- `J`：境外生产。

示例仅用于展示结构：

- `国药准字H20231234`
- `国药准字Z20231234`
- `国药准字S20231234`
- `国药准字HC20231234`
- `国药准字HJ20231234`

以上示例是格式样例，不代表真实获批产品。

### 2.2 测试与核验规则

1. OCR应保留完整前缀、字母和8位数字，不要把字母 `H/Z/S/C/J` 当成数字。
2. 只做正则匹配不能确认真伪。应同时比对药品名称、剂型、规格、上市许可持有人、生产企业等官方登记字段。
3. 同一批准文号可能对应不同包装规格；包装数量不同不必然代表批准文号不同。
4. 老包装或历史资料可能出现旧式进口药品注册证号等格式，不应强行改写成现行格式，应保留原文并进入官方数据库核验。
5. `OTC`是非处方药标识，不是批准文号；处方药也必须有合法的药品批准信息。

## 三、普通食品的生产许可证编号

### 3.1 普通食品通常没有产品“批准文号”

普通预包装食品通常实行生产许可和食品安全标准管理，不使用药品式的“一种产品一个批准文号”。包装上常见的 `SC` 编号是食品生产者的食品生产许可证编号，不是该商品的产品批准文号，也不能单独证明某项宣传功效。

### 3.2 `SC`编号格式

按照《食品生产许可管理办法》第三十条，食品生产许可证编号由 `SC` 和14位阿拉伯数字组成：

```text
SC + 3位食品类别编码 + 2位省级代码 + 2位市级代码
   + 2位县级代码 + 4位顺序码 + 1位校验码
```

结构示例：`SC12345678901234`（仅为格式占位，不代表真实许可证）。

### 3.3 测试与核验规则

1. `SC`后必须是14位数字；总长度为16个字符。
2. `SC`识别的是生产许可主体及其许可范围，不能仅凭编号确认某个具体产品已经获得单独审批。
3. 应核对生产者名称、生产地址、许可食品类别和许可证状态，确认产品是否在许可范围内。
4. 委托生产时，标签可能同时出现委托方和受托生产方；不能把品牌方名称直接当作获证生产者。
5. 产品标准号、配料表、营养成分表和食品类别名称用于判断产品属性，但均不能替代许可证核验。
6. 不得因为普通食品写有“压片糖果”“固体饮料”“代用茶”等名称，就将其识别为药品或保健食品。

## 四、保健食品注册号和备案号

保健食品属于食品，不是药品。依法注册或备案的保健食品应结合专有的“蓝帽子”标志、产品注册号或备案号、保健功能、适宜人群、不适宜人群及警示语等综合识别。

### 4.1 注册号

| 类型 | 现行格式 |
|---|---|
| 国产保健食品 | `国食健注G＋4位年代号＋4位顺序号` |
| 进口保健食品 | `国食健注J＋4位年代号＋4位顺序号` |

示例：`国食健注G20231234`、`国食健注J20231234`（仅为格式示例）。

其中 `G`用于国产产品，`J`用于进口产品。保健食品注册证书有效期为5年，核验时应关注证书状态、延续、变更和注销信息。

### 4.2 备案号

| 类型 | 现行格式 |
|---|---|
| 国产保健食品 | `食健备G＋4位年代号＋2位省级行政区域代码＋6位顺序编号` |
| 进口保健食品 | `食健备J＋4位年代号＋00＋6位顺序编号` |

示例：`食健备G202311123456`、`食健备J202300123456`（仅为格式示例）。

### 4.3 历史编号

旧包装、旧证书或历史库存中可能出现 `国食健字G/J＋8位数字` 等历史批准文号。历史格式不能仅因与现行格式不同就直接判假，也不能仅因形式正确就判真；应按包装标示原样记录，并查询官方注册、备案或历史数据。

### 4.4 包装识别和核验规则

1. 保健食品产品注册号/备案号与食品生产许可证编号是两类不同信息，包装上可能同时出现。
2. “蓝帽子”图形本身不能证明产品真实，应核对注册号或备案号对应的产品名称、注册人/备案人、保健功能、适宜人群、规格等。
3. 保健食品不得替代药物治疗疾病。出现“治疗、治愈、替代药物、停药”等宣传，应标记为高风险，而不是据此改判为药品。
4. 只有 `SC` 编号、没有可核验的保健食品注册号或备案号及相应标志时，不应把普通食品识别为保健食品。

## 五、建议的自动校验规则

以下表达式只适合做候选提取，不能代替官方核验：

```regex
# 境内药品
国药准字[HZS]\d{8}

# 港澳台或境外生产药品
国药准字[HZS][CJ]\d{8}

# 保健食品注册号
国食健注[ＧGＪJ]\d{8}

# 国产保健食品备案号
食健备[ＧG]\d{12}

# 进口保健食品备案号
食健备[ＪJ]\d{12}

# 食品生产许可证编号
SC\d{14}
```

OCR预处理建议：

- 将全角英文字母转换为半角并统一为大写；
- 去除编号内部误识别出的空格，但保留原始OCR文本供追溯；
- 谨慎处理 `0/O`、`1/I/l`、`5/S`、`8/B` 等混淆，不得静默猜测；
- 年份和顺序号位数不符时标记为 `unclear` 或 `format_invalid`；
- 格式通过后仍应进入官方查询，状态可区分为 `format_only`、`confirmed`、`mismatch`、`not_found`、`unclear`。

## 六、推荐核验流程

```text
读取包装编号
  → 判断前缀与类别
  → 检查格式和位数
  → 查询对应官方数据库
  → 比对产品名、主体、剂型/规格、功能及证书状态
  → 输出“确认/不一致/未查到/看不清”，不凭编号外观直接判真伪
```

不得混用的查询对象：

- 药品批准文号应进入国家药监局药品信息渠道核验；
- 保健食品注册号/备案号应进入市场监管部门的特殊食品信息渠道核验；
- `SC`编号应核验食品生产许可主体及许可范围；
- 电商详情页、搜索引擎摘要、自媒体文章和包装图片只能作为待核材料，不能替代监管登记信息。

## 八、使用边界

- 本文件用于分类、OCR和初筛规则，不构成行政认定、法律意见、医疗建议或购买建议。
- 对“未查到”结果，应先复核OCR、空格、全半角、证书变更和历史数据，再决定是否提示风险。
- 不得把编号格式校验结果写成“已确认真药”“已确认有效保健食品”或“已确认安全”。
- 监管规则和查询入口可能更新；正式测试发布前应重新检查上述官方来源。
