## 六、维护规则

1. 原始资料只放入 `data/source/` 或 `archive/`，不得被清洗结果覆盖。
2. 正式知识表更新后，同步检查 Coze 导入副本、来源映射和测试样本。
3. `material_value` 只来自用户材料或人工确认；`catalog_value` 只来自对应目录或官方记录，二者不得静默覆盖。
4. 医保药品编码匹配不代表医保报销资格、范围或比例。
5. 单个关键词、相似案例或单个药品字段不能独立构成诈骗、违法、真药或假药结论。
6. 信息不足时应返回缺失状态或补充材料提示，不得猜测剂量、禁忌、疗效或个体用药结论。
7. `archive/` 仅用于来源复核，不作为 Coze 导入或日常维护入口。
8. 网图只用于内部识别与流程测试；对外发布前必须再次确认授权，必要时替换为自摄或自制素材。

## 七、推荐交付顺序

```text
规则与字段确认
→ 正式数据和来源核对
→ 生成/检查 Coze 导入文件
→ 创建平台对象并回填 ID
→ 接口联调
→ 标准样本与边界样本测试
→ 修复后回归
→ 更新答辩材料
```
