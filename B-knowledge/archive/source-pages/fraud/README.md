# 原始防骗资料

原始材料优先保存官方HTML或PDF，文件名格式建议为：

```text
来源编号_短标题.html
来源编号_短标题.pdf
```

保存后应在`../防骗资料来源清单.csv`补充相对路径和核验状态；如需记录SHA-256，可写入备注或后续增加哈希清单。不得用清洗后的知识表覆盖原始资料。

当前共归档49份HTML和3份动态页面正文JSON，其中首批23份网页同时保留浏览器另存的资源目录；3份金融监管动态页以官方公开接口返回的JSON作为完整正文归档，HTML页面壳仅作辅助留存。50个登记来源均已有可用的本地归档路径，其中49个为外部网页来源，1个为项目内部安全规范。正式归档以本目录及`../防骗资料来源清单.csv`为准，不依赖工作区临时下载目录。
