| 字段 | 类型 | 说明 |
|------|------|------|
| `user_id` | VARCHAR(64) | 用户唯一标识 |
| `username` | VARCHAR(30) | 登录用户名，用于账户展示和头像首字 |
| `phone` | VARCHAR(20) | 手机号，接口返回时脱敏 |
| `login_type` | VARCHAR(20) | `sms` 或 `test_account` |
| `account_status` | VARCHAR(20) | `active` 或 `disabled` |
| `created_at` | TIMESTAMP | 创建时间 |
| `last_login_at` | TIMESTAMP | 最近登录时间 |
